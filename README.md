# agent-sop

A collection of Standard Operating Procedures (SOPs) for AI agents to follow when performing common tasks.

## Available SOPs

| SOP | Description |
|-----|-------------|
| [codebase-summary.sop.md](codebase-summary.sop.md) | Analyzes a codebase and generates comprehensive documentation including AGENTS.md, README.md, or custom documentation files |
| [aws-architecture-documentation.sop.md](aws-architecture-documentation.sop.md) | Documents AWS infrastructure architecture with verified diagrams, detailed component descriptions, and codebase context |

## Usage

Each SOP file follows a consistent structure:
- **Overview**: What the SOP accomplishes
- **Parameters**: Required and optional inputs
- **Steps**: Detailed procedural steps with constraints
- **Examples**: Sample inputs and outputs
- **Troubleshooting**: Common issues and solutions

SOPs are designed to be consumed by AI agents to ensure consistent, high-quality execution of complex tasks.
